# AI Quality Evaluation — Documentation

## Overview

A separate system for evaluating the quality of AI-generated educational content. Evaluates correctness, citation quality, error classification accuracy, recommendation quality, language appropriateness, stability, and safety.

## Evaluation Dimensions

| Dimension | Criteria |
|-----------|----------|
| Explanation correctness | Matches verified educational content |
| Material alignment | Consistent with available learning materials |
| Citation quality | Real, access-checked sources only |
| Error classification accuracy | Matches verified error categories |
| Recommendation quality | Follows documented decision rules |
| Language appropriateness | Matches student's locale (uz/ru/en) |
| Response stability | Consistent answers for same input |
| Safety | Age-appropriate, no PII leakage, no grade manipulation |

## Test Scenarios

Educational scenarios prepared in Uzbek, Russian, and English with verified reference answers and scoring criteria. Real student personal data is not used without appropriate authorization.

## Evaluation Reports

Results saved as separate reports, not mixed with production data.
